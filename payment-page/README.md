# 支払いページ（payment.html）

MetaMask以外のウォレットにも対応するための、単一HTMLファイルの支払いリクエストページです。静的ホスティングならどこにでも置けます。

## 使い方

`payment.html` を静的ホスト（GitHub Pages、各種ストレージの公開リンク、自前サーバーなど）に置き、URLパラメータで送金内容を渡します。

```text
payment.html?contract=0xE7C3D8C9a439feDe00D2600032D5dB0Be71C3c29&to=0xRecipientAddress&amount=100&chain=137
```

| パラメータ | 意味 | デフォルト |
| --- | --- | --- |
| `contract` | トークンのコントラクトアドレス | なし（必須） |
| `to` | 送金先アドレス | なし（必須） |
| `amount` | 金額（トークン単位、例 `100` や `1.5`） | なし（必須） |
| `symbol` | 表示する通貨記号 | `JPYC` |
| `decimals` | トークンの decimals | `18` |
| `chain` | チェーンID（Polygon = 137） | `137` |

パラメータの代わりに、HTML内のスクリプトより前に `window.PAYMENT_PARAMS = {contract: "...", to: "...", amount: "1", chain: "137"}` を定義して内容を固定した「1回限りのページ」を作ることもできます。一時的な支払いにはこちらが向いています。

## ページの動作

- ウォレットのアプリ内ブラウザで開かれた場合（`window.ethereum` がある場合）：「このウォレットで支払う」ボタンから、アカウント接続 → チェーン切替 → `eth_sendTransaction`（ERC-20 transfer）までをページが案内します。最終確認と署名はウォレットが行います
- 通常ブラウザの場合：「MetaMaskで開く」「Trust Walletで開く」ボタンと、MetaMask送金画面への直接リンクを表示します
- 全ウォレット共通のフォールバックとして、EIP-681 URIのQRコードとテキスト（コピー可）を表示します。QRライブラリはファイル内に同梱しているため、外部CDNに依存しません

## セキュリティと運用

- ページに載るのは宛先・金額・コントラクトだけで、いずれもブロックチェーン上の公開情報です。秘密鍵やシードフレーズの入力欄は存在しません
- ページ自体には送金する力がありません。送金は開いた人のウォレットでの確認と署名が必須で、送金先もページに固定されています
- 一時的な支払いでは、URLを推測できないものにし、個人が分かるメモを書かず、支払い確認後にページを削除してください
